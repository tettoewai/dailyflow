# DailyFlow

DailyFlow is a modern habit tracker built with **Expo** and **React Native**. It helps users build positive routines, stay consistent, and visualize their progress through streaks, reminders, and detailed statistics.

## ✨ Features

### Current

- 📅 Create, edit, and delete habits
- ✅ Track daily habit completion
- 🔥 Streak tracking
- 📊 Daily progress overview
- 📆 Calendar-based history
- 🔔 Reminder notifications
- 🎨 Clean and modern UI

### Planned

- 📈 Advanced analytics
- 🏆 Achievements & badges
- ⭐ XP and leveling system
- ☁️ Cloud synchronization
- 👥 Social challenges
- 🤖 AI-powered habit recommendations
- 📱 Home screen widgets

## 🚀 Getting Started

### Prerequisites

- Node.js (LTS recommended)
- npm, pnpm, or yarn
- Expo CLI
- Android Studio, Xcode, or Expo Go

### Installation

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npx expo start
```

Then open the app using:

- Android Emulator
- iOS Simulator
- Expo Go
- Development Build
